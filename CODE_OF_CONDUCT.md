# Major League Hacking (MLH) Code of Conduct

DataSetu is built in participation with the MLH Hackathon community. All participants, maintainers, and contributors must abide by the MLH Code of Conduct:

## 1. Respect and Inclusivity
- Be respectful, welcoming, and inclusive to people of all backgrounds, identities, and skill levels.
- Treat fellow hackers, mentors, organizers, and judges with courtesy and dignity.
- Harassment in any form—verbal, physical, or online—is strictly prohibited.

## 2. Fair Play & Integrity
- All code submitted during the hackathon must be written during the event.
- External libraries, datasets, and templates must be properly credited and open-source compliant.
- Do not exploit vulnerabilities, attack servers, or engage in unfair gaming of metrics.

## 3. Reporting Issues
If you encounter violations of this Code of Conduct, report them immediately to event organizers or repository maintainers.
