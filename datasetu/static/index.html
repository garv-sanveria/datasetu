• Pandas & SQL importers fail on rows 1-3 (preamble metadata).
• Splitting headers into row 4 & 5 creates duplicate / empty column keys.

• District names (`Bijapur`, `Poona`, `Gurgaon`) fail foreign key joins against modern census records.

2. Merged Header Repair

Detects 2-row merged column structures and joins parent + child headers into unambiguous semantic column keys.

3. Indian Numeral Engine

Standardizes Indian comma groupings (12,34,567), Lakhs, Crores, footnote asterisks, and sentinels to valid floats.

4. LGD Entity Disambiguation

Distinguishes duplicate district names (e.g. Bilaspur in HP vs CG, Aurangabad in MH vs BR) using state hints.
